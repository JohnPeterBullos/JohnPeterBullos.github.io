# Thesis Group Task Board

## Project Description

Thesis Group Task Board is a Flutter-based application designed to help students manage their thesis projects efficiently. It allows group leaders to organize thesis groups, assign tasks to members, and monitor research progress.

The application uses Supabase for user authentication and database management.

## Features

- User Registration and Login
- Thesis Group Management
- Group Member Management
- Task Assignment
- Task Priority and Due Dates
- Thesis Chapter Tracking
- Task Status Monitoring (Pending, In Progress, Completed)
- Dashboard with Task Statistics
- Supabase Database Integration
- Responsive User Interface

## Technologies Used

- Flutter
- Dart
- Supabase
- GitHub
- Visual Studio Code

## Installation and Setup

1. Install Flutter and VS Code.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run `flutter pub get`.
5. Configure your Supabase project URL and publishable API key.
6. Run the application using:

   `flutter run -d chrome --dart-define="SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY"`

The application requires access to a configured Supabase database with the appropriate tables and security policies.

## How to Use

1. Register or log in to your account.
2. Create a thesis group.
3. Add registered users as group members.
4. Assign thesis tasks to members.
5. Set priorities, chapters, and deadlines.
6. Monitor tasks through the dashboard.
7. Update task statuses as work progresses.
