# Group Task Board

## Project Description
Group Task Board is a thesis group task management system designed to help students organize research activities, collaborate with group members, assign tasks, and monitor project progress.

## Features
- User Registration and Login
- Dashboard
- Thesis Group Management
- Group Member Management
- Task Creation and Assignment
- Task Status Tracking
- Role-Based Access Control
- Supabase Database Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Supabase

## Installation and Setup
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html` using Live Server.
5. Register or log in to use the system.

An internet connection is required to access Supabase services.
